EMBER & OAK — Cafe Website Portfolio Demo
===========================================

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

How to preview:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed for Google Fonts and Unsplash photography.

Design features:
- Cinematic dark color grading, warm coffee palette, large photographic hero
- Responsive mobile navigation
- Story, menu, visit/contact sections
- Scroll reveal animations and hover effects
- Demo enquiry form (front-end only)

IMPORTANT BEFORE SHARING AS A REAL BUSINESS WEBSITE:
- This is a concept portfolio project.
- Replace the illustrative address, phone, email, social handle, menu and prices.
- The enquiry form does not send messages until connected to a backend/form service.
- Images load from Unsplash URLs and require internet access.

Suggested portfolio description:
"Designed and built a responsive café landing page concept using HTML, CSS, and JavaScript. Created a cinematic visual style, responsive navigation, menu cards, scroll animations, and a contact enquiry UI."
