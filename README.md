# ☕ Ember & Oak — Café Website

A modern, responsive café website concept built using **HTML, CSS, and JavaScript**. It features an elegant coffee-inspired design, menu cards, smooth scroll animations, and a sample enquiry form.

## ✨ Features

- **Modern Hero Section** — Full-screen café photography with elegant typography and call-to-action buttons.
- **Responsive Design** — Layout adapts to desktop, tablet, and mobile screens.
- **Mobile Navigation** — Toggleable navigation menu for smaller screens.
- **Our Story Section** — Dedicated section showcasing the café's concept and brand identity.
- **Interactive Menu Cards** — Displays sample coffee, bakery, and brunch items with prices.
- **Smooth Scroll Navigation** — Navigate between website sections smoothly.
- **Scroll Reveal Animations** — Sections animate into view while scrolling.
- **Hover Effects** — Interactive effects on buttons, menu cards, and images.
- **Visit & Contact Section** — Displays sample location, opening hours, and contact details.
- **Enquiry Form UI** — Includes name, email, guest selection, and message fields.
- **Dynamic Copyright Year** — Automatically updates the year in the footer.
- **SEO-Friendly Metadata** — Includes a page title, description, viewport settings, and theme color.

## 🛠️ Technologies Used

- CSS3
- JavaScript
- Google Fonts

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Ember-Oak-Cafe-Website.git
   ```

2. Open the project folder.
3. Open `index.html` in Chrome, Edge, or Firefox.
4. An internet connection is required for the external Google Fonts and Unsplash images.

## 📝 Important Notes

- This is a **portfolio demonstration project**, not a live café business website.
- The menu items and prices are illustrative.
- The address, phone number, email, and social handle are demo details and should be replaced before real-world use.
- The enquiry form is front-end only. It does not send emails or store bookings until connected to a backend or form service.
- External images and fonts may require an internet connection.
